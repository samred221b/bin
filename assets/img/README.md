# Image Assets

Place your local site images in this folder.

Required files referenced by the site:
- Bin.jpg — main portrait used in hero and about sections (`designer-portfolio/index.html`).
- favicon.svg — site favicon (already included).

Optional:
- Replace any Unsplash placeholder links in the portfolio grid with your own image files and adjust the `data-image` and `<img src>` accordingly.

Recommended sizes:
- Hero/About portrait (Bin.jpg): at least 1000x1000, optimized JPEG.
- Portfolio cards: 1600x1200 or similar aspect ratio 4:3, optimized JPEG.

Tips:
- Use descriptive filenames and keep them lowercase.
- Compress images (e.g., Squoosh.app) to improve page performance.
